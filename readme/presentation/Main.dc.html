SHARED STATE set / get
:tempo :beat :drums :bass_state :chord_state :bass_rec :chord_rec
With auto on, a loop re-reads its state every beat — which is why a fader move lands on the next beat, with nothing restarted. With it off, the loop keeps the values it started with.
